Windows Installation Instructions

  1. Unzip the downloaded file with Winzip/7zip/Winrar/etc.
  2. It’s recommended to move the Sim folder to your Program Files to help the Auto-Patcher work properly.
  3. Run the Sim in Admin mode to prevent most issues from patching or network play.

Troubleshooting Information

General Network Errors:

VPN: VPNs can mess up matchmaking. Alternatively, if you are on a particularly slow connection or live somewhere far from Unity data centers, a VPN could help the connection.

Mobile: Try switching between wi-fi and mobile data.

Windows: Make sure you are running the app in Admin mode. Additionally, Unity requires some machines to have ‘Time Sync’ turned on in their system settings.

Firewalls and various Antivirus programs can also prevent the game from talking on Port 7777.

Network Exception:

If you’re getting Exception errors with Unity Services / Inner Exceptions, try navigating to Users{USER}\AppData\LocalLow\ and Users{USER}\AppData\Local\ and deleting the ‘Batsu’ folders inside those locations.

Missing Fonts (Android):

If you are seeing pink/purple blocks instead of text in the sim, your device does not currently support one of the normal fonts used in the sim (Dela Gothic One, Segoe UI). Check if you’re able to reset your phone’s default fonts or install additional font packs.

Unable to Click (PC):

If you’re unable to click on certain UI options such as the deck selection, make sure that any gaming controllers are unplugged / not interfering with the sim. Take a look at other software such as Razer Synapse which have been known to cause input issues as well

Missing Decks:

If your decks aren’t appearing at all in the ‘Select Deck’ dropdown, try backing them all up to a different folder and deleting them all. There may be a deck that is corrupted causing the full list to fail.

Mac Installation Instructions

  1. Download using Safari instead of Chrome.
  2. Right-click and Open the RIGHT_CLICK_OPEN_ME_FIRST.command file
  3. Move the unzipped simulator to the Application folder, then launch it from the Finder menu.
    • 3a. Alternatively: Right click > show contents > go to MacOs folder and run the OPTCGSim
  4. To fix the “OPTCGSim is damaged” issue, you’ll need to add Read Permissions to the app:
    • 4a. Put the Sim into a folder, and that folder into “Applications”
    • 4b. Right-Click the folder and click on the “New Terminal at folder”
    • 4c. Copy and paste this command into the terminal – don’t run it yet:
      • xattr -r -d com.apple.quarantine
      • (MAKE SURE TO INCLUDE THE SPACE AT THE END)
    • 4d. Open the folder where the Sim is in on a new tab and drag and drop the sim into the terminal. That way you get the correct Application Path
    • 4e. Run the terminal

  1. Unzip the downloaded file
